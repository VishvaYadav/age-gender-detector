# models/

Trained model files go here.

| File | Made by | What it predicts |
|---|---|---|
| `base_age_gender_ethnicity.keras` | `notebooks/01_base_model_training.ipynb` | age, gender, ethnicity from a face |
| `labels.json` | same notebook | label names for gender and ethnicity |

After training on Kaggle, download both files from the notebook's **Output** tab (`/kaggle/working/models/`) and put them in this folder.
